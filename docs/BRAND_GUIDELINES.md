# IRG Brand Guidelines

## Brand Name

IRG

---

# Brand Personality

IRG is a premium fashion brand built around confidence, simplicity, quality, and timeless style.

The brand should feel:

- Modern
- Elegant
- Premium
- Minimal
- Luxurious
- Confident
- Clean

---

# Design Principles

Every page should feel:

- Spacious
- Fast
- Premium
- Easy to navigate
- Professional

Avoid clutter.

Every element should have purpose.
